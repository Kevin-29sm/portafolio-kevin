# Kevin Ortiz | Web Portfolio

Personal portfolio page built with **HTML, CSS and JavaScript** for the English I course (Third cut, integrating project).

## Features

- Responsive page with a **home** section, a **menu** (button for mobile) and links to each section.
- **Language switcher** (English / Spanish) using a translation dictionary in `script.js`.
- Sections: Home, About me, Skills, Education, Projects and Contact.
- Contact form with a **button** to send the message.

## Project structure

```
portfolio-kevin/
├── index.html   # page structure (content)
├── style.css    # design and responsive layout
├── script.js    # language switcher, menu and form
├── README.md    # this file
└── NOTES.md     # work notes and rubric checklist
```

## How to run it

1. Download or clone the repository.
2. Open `index.html` in your browser (or use the *Live Server* extension in VS Code).
